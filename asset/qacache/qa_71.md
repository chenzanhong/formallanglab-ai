# 下推自动机（PDA）

## 下推自动机的定义

下推自动机（Pushdown Automaton，PDA）是一种比有限自动机（FA）更强大的计算模型。它是上下文无关文法（CFG）的识别器，能够识别上下文无关语言。

### 形式化定义

下推自动机是一个七元组：
\[ M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F) \]

其中：
- **Q** 是有限状态集合
- **Σ** 是输入字母表（终结符集合）
- **Γ** 是栈字母表（栈符号集合）
- **δ** 是转移函数，形式为：
  \[ \delta: Q \times (\Sigma \cup \{\epsilon\}) \times \Gamma \to 2^{Q \times \Gamma^*} \]
- **q₀** 是初始状态
- **Z₀** 是初始栈符号
- **F** 是接受状态集合

### 转移函数解释

转移函数δ(q, a, X)定义了在状态q、输入字符a（或ε表示不读取输入）、栈顶符号X时，PDA可以转移到的状态集合和栈操作。每个转移可以：
1. 改变当前状态
2. 修改栈顶内容（弹出X，压入任意符号串）
3. 可能消耗一个输入字符

## 下推自动机的类型

### 1. 确定性下推自动机（DPDA）
- 对于任何状态q、输入a和栈顶符号X，δ(q, a, X)最多包含一个元素
- 不允许在同一状态、输入和栈顶符号下有多个选择

### 2. 非确定性下推自动机（NPDA）
- 对于某些状态q、输入a和栈顶符号X，δ(q, a, X)可能包含多个元素
- 允许在转移时有多种选择

### 重要区别
- NPDA比DPDA更强大：NPDA可以识别所有上下文无关语言，而DPDA只能识别上下文无关语言的一个子集
- 确定性和非确定性PDA不等价，这与有限自动机不同（DFA和NFA等价）

## 接受方式

### 1. 终态接受
PDA在读完整个输入串后，如果处于接受状态F中的某个状态，则接受该输入。

### 2. 空栈接受
PDA在读完整个输入串后，如果栈为空，则接受该输入。

这两种接受方式是等价的，可以相互转换。

## 与有限自动机的主要区别

| 特性 | 下推自动机（PDA） | 有限自动机（FA） |
|------|-----------------|----------------|
| 存储结构 | 无限下推栈 | 无额外存储（仅状态） |
| 状态记忆 | 有限状态 + 无限栈内容 | 仅有限状态 |
| 识别能力 | 上下文无关语言（NPDA） | 正则语言 |
| 确定性等价 | DPDA < NPDA（不等价） | DFA ≡ NFA（等价） |
| 对应文法 | 上下文无关文法 | 正则文法 |
| 复杂度 | 更高 | 更低 |

## 核心区别详解

### 1. 存储能力的提升
- **有限自动机**：只能通过有限数量的状态来记忆信息，无法记住无限多的状态或计数
- **下推自动机**：通过无限的下推栈提供额外的存储能力，可以：
  - 跟踪嵌套深度（如括号匹配）
  - 记住前面的输入（如回文检测）
  - 模拟递归过程

### 2. 识别能力的差异
- **有限自动机**：只能识别正则语言，如a*b+、(ab)*等
- **下推自动机**：可以识别更复杂的上下文无关语言，如：
  - 括号匹配：{ (^n )^n | n ≥ 0 }
  - 回文语言：{ w w^R | w ∈ Σ^* }
  - 等数量配对：{ a^n b^n | n ≥ 0 }

### 3. 计算模型的复杂度
- **有限自动机**：
  - 决策过程简单（状态转换表）
  - 存在多项式时间甚至线性时间的识别算法
  - 实现效率高

- **下推自动机**：
  - 决策过程更复杂（涉及栈操作和可能的回溯）
  - 一般需要更复杂的识别算法
  - 实现相对复杂

### 4. 确定性与非确定性
- **有限自动机**：DFA和NFA等价，可以相互转换
- **下推自动机**：DPDA和NPDA不等价，NPDA更强大

## 下推自动机的应用

1. **语法分析**：作为上下文无关语言的识别器，用于编译器前端
2. **模式匹配**：识别具有嵌套结构的模式
3. **自然语言处理**：解析某些自然语言结构
4. **形式验证**：验证具有递归结构的系统属性
5. **字符串处理**：处理需要平衡括号等结构的字符串

## 示例：接受语言{ a^n b^n | n ≥ 0 }的PDA

考虑一个NPDA接受所有形如a^n b^n的字符串：

- 状态集合Q = {q0, q1, q2}
- 输入字母表Σ = {a, b}
- 栈字母表Γ = {Z0, A}
- 初始状态q0
- 初始栈符号Z0
- 接受状态F = {q2}

转移函数定义：
1. δ(q0, a, Z0) = {(q0, AZ0)} - 读取a，将A压入栈
2. δ(q0, a, A) = {(q0, AA)} - 读取a，将A压入栈
3. δ(q0, ε, Z0) = {(q2, Z0)} - 空串情况（n=0）
4. δ(q0, b, A) = {(q1, ε)} - 读取b，弹出栈顶A
5. δ(q1, b, A) = {(q1, ε)} - 读取b，弹出栈顶A
6. δ(q1, ε, Z0) = {(q2, Z0)} - 栈底符号出现，接受

这个PDA通过栈来记录a的数量，然后在遇到b时弹出对应的A，当所有a和b匹配且栈回到初始状态时接受输入。

下推自动机作为上下文无关文法的识别器，是形式语言理论和编译原理中的关键概念，它弥补了有限自动机在处理嵌套和递归结构方面的不足，为更复杂的语言处理提供了理论基础。
