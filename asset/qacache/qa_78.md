# 递归语言和递归可枚举语言

递归语言和递归可枚举语言是计算理论中两个重要的语言类，它们在乔姆斯基层次结构中位于0型语言的范畴，与图灵机密切相关。

## 递归语言

### 定义

递归语言（Recursive Language，也称为可判定语言或Turing可判定语言）是指存在一个图灵机，它可以：

- 对于语言中的任何字符串，该图灵机最终会停机并接受它
- 对于语言外的任何字符串，该图灵机最终会停机并拒绝它

换句话说，递归语言的成员资格问题是**可判定的**（decidable），即存在一个算法可以在有限时间内确定任何字符串是否属于该语言。

### 形式化定义

设L是字母表Σ上的语言，L是递归语言当且仅当存在一个图灵机M，使得：
- 对于所有w ∈ L，M在输入w上停机并接受
- 对于所有w ∉ L，M在输入w上停机并拒绝

### 递归语言的性质

1. **封闭性**：递归语言在补、并、交、连接和Kleene星号等操作下是封闭的
2. **包含关系**：所有上下文无关语言都是递归语言
3. **成员测试**：存在算法可以在有限时间内测试成员资格
4. **图灵机特征**：可被总是停机的图灵机识别

## 递归可枚举语言

### 定义

递归可枚举语言（Recursively Enumerable Language，也称为Turing可识别语言）是指存在一个图灵机，它可以：

- 对于语言中的任何字符串，该图灵机最终会停机并接受它
- 对于语言外的任何字符串，该图灵机可能停机并拒绝，或者永远运行下去（永不停机）

换句话说，递归可枚举语言的成员资格问题是**半可判定的**（semi-decidable），即存在一个算法可以在有限时间内确认一个字符串属于该语言，但对于不属于该语言的字符串，算法可能永远运行下去。

### 形式化定义

设L是字母表Σ上的语言，L是递归可枚举语言当且仅当存在一个图灵机M，使得：
- 对于所有w ∈ L，M在输入w上停机并接受
- 对于所有w ∉ L，M在输入w上要么停机并拒绝，要么无限运行

### 递归可枚举语言的性质

1. **封闭性**：递归可枚举语言在并、交、连接和Kleene星号等操作下是封闭的，但在补操作下不封闭
2. **包含关系**：所有递归语言都是递归可枚举语言，但反之不成立
3. **成员测试**：存在算法可以在有限时间内确认成员资格，但可能无法确认非成员资格
4. **图灵机特征**：可被图灵机识别，无论是否停机

## 递归语言与递归可枚举语言的关系

### 包含关系

递归语言类是递归可枚举语言类的真子集，即：
- 每个递归语言都是递归可枚举语言
- 存在递归可枚举语言不是递归语言

这一关系可以表示为：递归语言 ⊂ 递归可枚举语言

### 重要定理

**定理1**：一个语言L是递归的当且仅当L和它的补集Ľ都是递归可枚举的。

**定理2**：存在递归可枚举语言的补集不是递归可枚举的。这表明递归可枚举语言在补操作下不封闭。

### 图灵机视角的区别

从图灵机的角度来看：

- **递归语言**：可以被**总是停机**的图灵机识别（称为判定器，decider）
- **递归可枚举语言**：可以被图灵机识别，但该图灵机**可能不停机**（称为识别器，recognizer）

## 例子

### 递归语言的例子

1. **上下文无关语言**：如括号匹配语言{ ()^n | n ≥ 0 }
2. **正则语言**：如a^n b^n | n ≥ 0 }
3. **某些算术问题**：如判定一个数是否为素数的问题

### 递归可枚举但非递归的语言的例子

1. **停机问题**：语言H = { ⟨M, w⟩ | M是一个图灵机，M在输入w上停机 }
   - H是递归可枚举的：可以构造一个通用图灵机模拟M在w上的运行
   - H不是递归的：停机问题是不可判定的

2. **邮政对应问题**：也是递归可枚举但非递归的

## 判定与半判定

### 判定问题

一个问题是可判定的，如果存在一个算法可以在有限时间内对任意输入给出正确答案（是或否）。对应的语言是递归语言。

### 半判定问题

一个问题是半可判定的，如果存在一个算法可以在有限时间内确认肯定答案，但对于否定答案可能永远运行下去。对应的语言是递归可枚举语言。

## 理论意义

1. **计算能力边界**：递归语言和递归可枚举语言帮助我们理解计算的边界，区分哪些问题是可算法解决的，哪些不是

2. **乔姆斯基层次**：递归可枚举语言对应0型文法生成的语言，递归语言则是其子集

3. **停机问题**：是递归可枚举但非递归语言的典型例子，证明了算法求解能力的局限性

4. **可计算性理论**：这两个语言类是可计算性理论的基础概念，与图灵机、丘奇-图灵论题等核心概念密切相关

递归语言和递归可枚举语言的区别和联系反映了计算理论中的一个基本事实：存在问题是可以通过算法部分解决（半判定）的，但不能完全解决（判定）的。这一发现对计算机科学和数学基础产生了深远影响，标志着不可判定性理论的诞生。
