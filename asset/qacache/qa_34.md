# 构造接受以01结尾字符串的DFA

## 语言定义

我们需要构造的DFA接受的语言是：

**L = { w | w 以 "01" 结尾，w ∈ {0,1}^* }**

这包括所有以01结尾的二进制字符串，例如：01, 101, 001, 1101等。

## 构造思路

构造此类DFA的关键是**跟踪输入字符串的结尾部分**，特别是我们需要：
1. 记录我们是否已经看到了一个0
2. 在看到0之后，是否紧接着看到了1

## 状态设计

我们可以设计以下三个状态：

- **q0**：初始状态，表示尚未看到符合条件的结尾部分
- **q1**：中间状态，表示最后一个字符是0
- **q2**：接受状态，表示最后两个字符是01

## 形式化定义

DFA M 可以形式化定义为：

**M = ({q0, q1, q2}, {0, 1}, δ, q0, {q2})**

其中转移函数 δ 定义如下：

| 当前状态 | 输入0 | 输入1 |
|---------|------|-------|
| q0      | q1   | q0    |
| q1      | q1   | q2    |
| q2      | q1   | q0    |

## 状态转移图

```
    0         0
  ┌───┐     ┌───┐     ┌───┐
  │   │     │   │     │   │
0 │   │     │   │     │   │0
  │   ▼     │   ▼     │   ▼
┌───────┐   ┌───────┐   ┌───────┐
│       │   │       │   │       │
│  q0   │──>│  q1   │──>│  q2   │
│       │<──│       │<──│       │
└───────┘   └───────┘   └───────┘
  │           │           │
  │           │           │
  └───────────┴───────────┘
              1
```

## 转移函数说明

### q0状态的转移
- **读取0**：转移到q1，表示我们看到了一个可能的01序列的开始
- **读取1**：保持在q0，因为1不能作为01序列的第一个字符

### q1状态的转移
- **读取0**：保持在q1，因为新的0可能开始一个新的01序列
- **读取1**：转移到接受状态q2，因为我们成功匹配了01序列

### q2状态的转移
- **读取0**：转移到q1，因为新的0可能开始一个新的01序列
- **读取1**：转移回q0，因为新的1意味着当前结尾不再是01

## 工作原理分析

### 空串处理
- 空串不被接受，因为它不以01结尾
- 初始状态q0不是接受状态

### 单字符处理
- 单个0：在q1状态，不接受
- 单个1：在q0状态，不接受

### 多字符处理
- 当看到01序列时进入接受状态q2
- 如果后续还有输入，根据新字符更新状态
- 最终状态决定是否接受整个字符串

## 接受字符串示例

### 示例1：输入 "01"
- 初始：q0
- 读取0：q0 → q1
- 读取1：q1 → q2（接受状态）
- 结果：接受

### 示例2：输入 "101"
- 初始：q0
- 读取1：q0 → q0
- 读取0：q0 → q1
- 读取1：q1 → q2（接受状态）
- 结果：接受

### 示例3：输入 "0011"
- 初始：q0
- 读取0：q0 → q1
- 读取0：q1 → q1
- 读取1：q1 → q2
- 读取1：q2 → q0（非接受状态）
- 结果：拒绝

## 设计正确性证明

我们可以通过归纳法证明这个DFA确实接受所有以01结尾的字符串：

1. **基础情况**：字符串"01"被接受
2. **归纳步骤**：假设对于任何以01结尾的字符串w，DFA接受w
   - 考虑字符串w' = w0：以0结尾，不在L中，DFA在q1状态（正确拒绝）
   - 考虑字符串w' = w1：以1结尾，不在L中，DFA在q0状态（正确拒绝）
   - 考虑字符串w' = x01（x是任意字符串）：DFA在处理完x01后会进入q2状态（正确接受）

## 最小化分析

这个DFA已经是最小的，因为：

1. 没有不可达状态
2. 所有状态都是可区分的：
   - q0和q1可以通过输入1区分（q0→q0，q1→q2）
   - q0和q2可以通过输入0区分（q0→q1，q2→q1），但更重要的是q2是接受状态而q0不是
   - q1和q2可以通过输入1区分（q1→q2，q2→q0）

## 总结

构造接受以01结尾字符串的DFA需要三个状态：初始状态、中间状态和接受状态。关键是正确设计状态转移函数，以跟踪字符串的结尾部分。这个DFA设计既简洁又高效，能够正确识别所有以01结尾的二进制字符串。
