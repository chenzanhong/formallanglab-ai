# 乔姆斯基范式

## 乔姆斯基范式的定义

乔姆斯基范式（Chomsky Normal Form，CNF）是上下文无关文法的一种标准形式，由语言学家Noam Chomsky提出。

**定义**：一个上下文无关文法G = (V, T, P, S)被称为是乔姆斯基范式，如果它的所有产生式都具有以下两种形式之一：

1. **二元产生式**：A → BC，其中A, B, C ∈ V（B和C是非终结符）
2. **终结符产生式**：A → a，其中A ∈ V，a ∈ T（A是非终结符，a是终结符）

此外，乔姆斯基范式不允许ε产生式（A → ε），除非起始符号S不出现在任何产生式的右侧，并且S → ε是唯一的ε产生式。在实际应用中，通常要求更严格，完全不允许ε产生式（除了可能的S → ε，当且仅当ε ∈ L(G)时）。

## 将上下文无关文法转换为乔姆斯基范式的步骤

任何不含ε产生式（或仅包含S → ε且S不在其他产生式右侧）的上下文无关文法都可以转换为等价的乔姆斯基范式。转换过程通常包括以下几个步骤：

### 步骤1：消除ε产生式

ε产生式是形如A → ε的产生式。消除过程如下：

1. 找出所有可以推导出ε的非终结符（包括直接通过A → ε和间接推导）
2. 对于每个产生式A → α，添加所有可能的通过删除α中的可空非终结符得到的产生式
3. 如果起始符号S可以推导出ε，添加新的起始符号S'和产生式S' → S | ε

### 步骤2：消除单元产生式

单元产生式是形如A → B的产生式，其中A和B都是非终结符。消除过程如下：

1. 对于每个非终结符A，找出所有可以通过单元产生式链从A推导出的非终结符B
2. 对于每个这样的B，将所有B → α（非单元产生式）转换为A → α
3. 删除所有单元产生式

### 步骤3：分解长产生式

将任何产生式A → X₁X₂...Xₖ（k ≥ 3，X_i是终结符或非终结符）分解为二元产生式：

1. 引入新的非终结符B₁, B₂, ..., Bₖ₋₂
2. 将A → X₁X₂...Xₖ替换为：
   - A → X₁B₁
   - B₁ → X₂B₂
   - ...
   - Bₖ₋₂ → Xₖ₋₁Xₖ

### 步骤4：处理混合产生式

对于形如A → αβ的产生式，其中α或β是终结符，需要将终结符替换为非终结符：

1. 对于每个终结符a，引入一个新的非终结符A_a和产生式A_a → a
2. 将产生式中的每个终结符a替换为对应的非终结符A_a

## 转换示例

### 原始文法
考虑以下简单的上下文无关文法：
```
S → AB | a
A → aA | ε
B → b
```

### 步骤1：消除ε产生式

可空非终结符：A

修改产生式：
- S → AB | A | B | a（删除A或B，如果它们可空）
- A → aA | a（删除A中的ε）
- B → b

如果需要，添加新的起始符号S'：
```
S' → S | ε
S → AB | A | B | a
A → aA | a
B → b
```

### 步骤2：消除单元产生式

单元产生式链：
- S' → S
- S → A | B

替换单元产生式：
```
S' → AB | aA | a | b | ε
S → AB | aA | a | b
A → aA | a
B → b
```

### 步骤3：分解长产生式
当前没有需要分解的长产生式（k ≥ 3）。

### 步骤4：处理混合产生式
引入新的非终结符：
- A_a → a
- A_b → b

修改产生式：
```
S' → AB | A_aA | A_a | A_b | ε
S → AB | A_aA | A_a | A_b
A → A_aA | A_a
B → A_b
A_a → a
A_b → b
```

### 最终的乔姆斯基范式
如果不考虑ε产生式，可以得到：
```
S' → AB | A_aA | A_a | A_b
S → AB | A_aA | A_a | A_b
A → A_aA | A_a
B → A_b
A_a → a
A_b → b
```

## 乔姆斯基范式的性质

1. **推导长度**：对于长度为n的字符串，在乔姆斯基范式中，最左推导恰好有2n-1步
2. **树形结构**：推导树是一个二叉树，每个内部节点恰好有两个子节点
3. **算法优势**：许多语法分析算法（如CYK算法）要求文法是乔姆斯基范式
4. **理论价值**：简化了许多理论证明和分析

## 应用

乔姆斯基范式在以下领域有重要应用：

1. **语法分析**：CYK算法需要输入文法是乔姆斯基范式
2. **语言理论**：证明上下文无关语言的性质
3. **编译器设计**：规范化文法以便于处理
4. **形式语言研究**：简化语言复杂度的分析

乔姆斯基范式作为上下文无关文法的一种标准形式，提供了一种统一的方式来表示和处理上下文无关语言，对于理论研究和实际应用都具有重要意义。
