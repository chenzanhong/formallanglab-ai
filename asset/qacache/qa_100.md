# 证明{aⁿbⁿcⁿ | n ≥ 0}不是上下文无关语言

## 证明过程（使用泵引理）

我们将使用上下文无关语言的泵引理来证明语言L = {aⁿbⁿcⁿ | n ≥ 0}不是上下文无关的。

### 步骤1：假设L是上下文无关语言

根据泵引理，如果L是上下文无关语言，则存在一个泵长度p，使得对于L中所有长度大于等于p的字符串w，都可以划分成w = uvxyz，满足泵引理的三个条件。

### 步骤2：选择目标字符串

选择字符串w = aᵖbᵖcᵖ，显然w属于L且|w| = 3p ≥ p（当p ≥ 1时）。

### 步骤3：考虑所有可能的划分方式

根据泵引理，w = uvxyz，其中|vxy| ≤ p且vy ≠ ε。我们需要考虑vxy可能的所有位置：

#### 情况1：vxy只包含a
- 此时，u = aⁿ, v = aᵏ, x = aᵐ, y = ε, z = a^(p-n-k-m)bᵖcᵖ
- 当我们泵i = 2时，得到uv²xy²z = a^(p+k)bᵖcᵖ，这不再属于L，因为a的数量多于b和c

#### 情况2：vxy只包含b
- 类似情况1，泵i = 2时，b的数量会超过a和c的数量，结果不在L中

#### 情况3：vxy只包含c
- 同样，泵i = 2时，c的数量会超过a和b的数量，结果不在L中

#### 情况4：vxy包含a和b（但不包含c）
- 此时vxy跨过a和b的边界，但|vxy| ≤ p
- 假设v = aᵏ, y = bʳ，其中k + r ≥ 1（因为vy ≠ ε）
- 当泵i = 2时，得到a^(p+k)b^(p+r)cᵖ，此时a和b的数量都大于c的数量，且a和b的数量不相等，结果不在L中

#### 情况5：vxy包含b和c（但不包含a）
- 类似情况4，泵i = 2时，b和c的数量会增加，导致与a的数量不相等，结果不在L中

#### 情况6：vxy包含a、b和c
- 由于|vxy| ≤ p，而w中a、b、c各有p个，所以vxy最多只能包含其中一个完整的字符组加上部分另一个字符组
- 无论如何划分，泵操作后必然导致三个字符的数量不再相等，结果不在L中

### 步骤4：得出矛盾

在所有可能的划分情况下，我们都找到了至少一个i值（通常是i = 2或i = 0）使得uvⁱxyⁱz不属于L，这违反了泵引理的第三个条件。

### 步骤5：结论

因此，我们的初始假设错误，L = {aⁿbⁿcⁿ | n ≥ 0}不是上下文无关语言。
