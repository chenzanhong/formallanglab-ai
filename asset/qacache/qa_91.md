# 线性有界自动机识别的语言类

## 线性有界自动机概述

线性有界自动机（Linear Bounded Automaton，简称LBA）是一种受限的图灵机，它的工作空间受到输入字符串长度的线性限制。具体来说，LBA的读写头只能在包含输入字符串的区域及其有限扩展（线性增长）的区域内移动。

## LBA识别的语言类

线性有界自动机识别的语言类被称为**上下文有关语言**（Context-Sensitive Languages，简称CSL）。这些语言对应于乔姆斯基层级中的**1型文法**（Type-1 Grammars）。

## 上下文有关语言的特性

1. **定义**：上下文有关语言是可以被线性有界自动机识别的语言类。

2. **文法表示**：上下文有关语言可以由上下文有关文法（1型文法）生成。上下文有关文法的产生式具有形式 αAβ → αγβ，其中A是非终结符，α、β、γ是符号串，且γ不为空。

3. **包含关系**：
   - 所有上下文无关语言都是上下文有关语言
   - 所有上下文有关语言都是递归可枚举语言
   - 存在上下文有关语言不是上下文无关语言

## LBA的特性

1. **工作空间限制**：LBA的工作带长度与输入长度成正比，通常为k·n，其中n是输入长度，k是常数。

2. **停机性**：与图灵机不同，LBA总是会停机。对于任何输入，LBA在有限步后必须接受或拒绝。

3. **与图灵机的区别**：LBA是图灵机的特例，其工作空间受到输入长度的线性限制。

## 示例

一个经典的上下文有关语言的例子是：{aⁿbⁿcⁿ | n ≥ 0}，这个语言不能被上下文无关文法描述，但可以被线性有界自动机识别。
