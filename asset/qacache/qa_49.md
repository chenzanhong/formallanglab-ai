# 语法分析树（Syntax Tree / Parse Tree）

## 定义

**语法分析树**（Syntax Tree 或 Parse Tree）是一种**树形数据结构**，用于表示上下文无关文法（CFG）中句子的推导过程。它直观地展示了句子是如何从开始符号通过一系列产生式推导出来的。

## 基本组成

语法分析树由以下部分组成：

- **根节点**：表示**开始符号**（Start Symbol），通常为 S
- **内部节点**：表示**非终结符**（Non-terminal symbols）
- **叶子节点**：表示**终结符**（Terminal symbols）
- **边**：表示推导过程中的一步替换

## 构建规则

1. **根节点**必须是文法的开始符号
2. **每个内部节点**必须是非终结符
3. **每个叶子节点**必须是终结符或 ε（空串）
4. **如果一个内部节点 A** 有子节点 \( X_1, X_2, ..., X_k \)，那么必须存在产生式 \( A 	o X_1 X_2 ... X_k \)
5. **叶子节点**从左到右组成的序列就是**被推导的句子**

## 示例

### 文法定义

考虑以下简单的上下文无关文法：

```
S → E
E → E + T | E - T | T
T → T * F | T / F | F
F → ( E ) | id | num
```

### 句子示例

对于表达式 `id + id * num`，其语法分析树如下：

```
      S
      |
      E
      |
      +
    /   \
   E     T
   |     |
   T     *
   |    / \
   F   T   F
   |   |   |
  id  F  num
      |
     id
```

### 推导过程

对应的最左推导：

```
S ⇒ E
  ⇒ E + T
  ⇒ T + T
  ⇒ F + T
  ⇒ id + T
  ⇒ id + T * F
  ⇒ id + F * F
  ⇒ id + id * F
  ⇒ id + id * num
```

## 语法分析树的性质

1. **结构完整性**：树的结构反映了产生式的应用顺序
2. **二义性表示**：对于二义性文法，同一个句子可能对应多个不同的语法分析树
3. **叶子顺序**：从左到右读取叶子节点，得到原句子
4. **内部节点结构**：内部节点的子节点序列对应产生式右侧的符号序列

## 与抽象语法树（AST）的区别

| 特性 | 语法分析树 | 抽象语法树 |
|------|------------|------------|
| **细节保留** | 保留所有文法细节，包括括号、操作符等 | 省略不必要的细节，更注重语义结构 |
| **节点数量** | 通常节点数较多 | 节点数较少，更简洁 |
| **用途** | 语法分析阶段，验证语法正确性 | 语义分析和代码生成阶段 |
| **操作符位置** | 操作符通常作为内部节点的父节点 | 操作符通常作为内部节点本身 |

## 语法分析树的应用

1. **语法验证**：验证输入字符串是否符合文法规则
2. **编译器前端**：作为词法分析后的下一步，为后续的语义分析和代码生成提供基础
3. **自然语言处理**：分析句子结构，帮助理解语法关系
4. **模式识别**：识别和分析复杂的模式结构

## 构建方法

语法分析树可以通过以下方法构建：

1. **自上而下分析**：
   - 递归下降分析
   - 预测分析（LL 分析）

2. **自下而上分析**：
   - 移进-归约分析（LR 分析）
   - SLR、LALR、Canonical LR 分析

## 示例：简单赋值语句的语法分析树

### 文法

```
S → id = E
E → E + T | T
T → T * F | F
F → id | num | ( E )
```

### 语句 `x = y + 3 * z` 的语法分析树

```
      S
     /|\
    / | \
  id  =  E
  |     |
  x     +
       / \
      E   T
      |   |
      T   *
      |  / \
      F T   F
      | |   |
     id F  id
        |   |
        3   z
```

## 总结

语法分析树是上下文无关文法中句子推导过程的可视化表示，它：

1. 根节点为开始符号，内部节点为非终结符，叶子节点为终结符
2. 从左到右读取叶子节点得到原句子
3. 每个内部节点及其子节点对应一条产生式的应用
4. 是语法分析的核心数据结构，为编译器和解释器提供语法层面的理解
