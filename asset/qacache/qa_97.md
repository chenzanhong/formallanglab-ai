# 二义性语言和二义性文法的区别

## 基本概念

### 二义性文法

**二义性文法（Ambiguous Grammar）**是指存在至少一个句子可以有多个不同的最左推导或最右推导，或者说存在多个不同的分析树。

形式定义：一个上下文无关文法G是二义的，当且仅当存在至少一个字符串w ∈ L(G)，使得w有两个或更多不同的最左推导（或最右推导）。

### 二义性语言

**二义性语言（Inherently Ambiguous Language）**是指所有生成该语言的文法都是二义的。换句话说，该语言本质上无法用非二义的上下文无关文法来描述。

## 主要区别

| 特性 | 二义性文法 | 二义性语言 |
|------|------------|------------|
| 定义 | 单个文法具有二义性 | 所有生成该语言的文法都是二义的 |
| 可消除性 | 某些二义性文法可以转换为等价的非二义文法 | 无法消除二义性，所有文法都必然是二义的 |
| 本质 | 文法的属性 | 语言本身的属性 |
| 判定难度 | 存在算法可以检测特定文法是否二义 | 没有算法可以判定一个语言是否是本质二义的 |

## 示例

### 二义性文法示例

下面是一个二义性文法的经典例子，用于生成算术表达式：

```
E → E + E | E * E | (E) | id
```

这个文法是二义的，因为表达式"id + id * id"有两个不同的最左推导和两个不同的分析树，对应于不同的运算符优先级解释。

然而，我们可以通过引入优先级和结合性规则，将其转换为非二义的文法：

```
E → E + T | T
T → T * F | F
F → (E) | id
```

### 二义性语言示例

一个著名的二义性语言例子是：

L = {aⁿbᵐcᵏ | n = m 或 m = k} ∪ {aⁿbⁿcⁿ | n ≥ 0}

可以证明，所有生成这个语言的上下文无关文法都必然是二义的。

## 重要结论

1. **二义性文法是针对单个文法而言的**，而二义性语言是针对所有可能生成该语言的文法而言的。

2. **并非所有的上下文无关语言都有非二义的文法**，存在本质上二义的上下文无关语言。

3. **二义性文法的判定是不可判定的**，即不存在算法可以检查任意上下文无关文法是否是二义的。

4. **二义性语言的判定也是不可判定的**，即不存在算法可以检查任意上下文无关语言是否是本质二义的。
