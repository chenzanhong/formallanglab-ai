# 上下文无关文法中消除左递归

左递归是上下文无关文法中的一种常见形式，指产生式的左侧非终结符出现在右侧的开头。左递归会导致自顶向下解析器陷入无限循环，因此需要消除。左递归分为两种类型：直接左递归和间接左递归。

## 直接左递归

直接左递归是指产生式形如A → Aα | β，其中α和β是文法符号串，且β不以A开头。

### 消除直接左递归的方法

对于形如A → Aα₁ | Aα₂ | ... | Aαₘ | β₁ | β₂ | ... | βₙ的产生式（其中βᵢ不以A开头），可以转换为：

```
A → β₁A' | β₂A' | ... | βₙA'
A' → α₁A' | α₂A' | ... | αₘA' | ε
```

其中A'是新引入的非终结符。

### 示例1：消除直接左递归

**原始文法：**
```
E → E + T | T
T → T * F | F
F → (E) | a
```

这里E和T都有直接左递归。

**消除E的左递归：**
```
E → TE'
E' → +TE' | ε
```

**消除T的左递归：**
```
T → FT'
T' → *FT' | ε
```

**消除左递归后的文法：**
```
E → TE'
E' → +TE' | ε
T → FT'
T' → *FT' | ε
F → (E) | a
```

## 间接左递归

间接左递归是指通过多个产生式的推导，导致非终结符最终出现在自身推导的开头。例如，A → Bα, B → Aβ 形成了间接左递归。

### 消除间接左递归的步骤

消除间接左递归的一般步骤如下：

1. **排序非终结符**：将所有非终结符排序为A₁, A₂, ..., Aₙ

2. **逐步消除左递归**：对于每个i从1到n：
   - 对于每个j从1到i-1：
     - 将每个形如Aᵢ → Aⱼγ的产生式替换为Aᵢ → δ₁γ | δ₂γ | ... | δₖγ，其中Aⱼ → δ₁ | δ₂ | ... | δₖ是当前所有Aⱼ的产生式
   - 消除Aᵢ的直接左递归

3. **删除无用产生式**：删除可能产生的无法从起始符号到达的非终结符和无法推导出终结符串的产生式

### 示例2：消除间接左递归

**原始文法：**
```
S → Aa | b
A → Bb | c
B → Sc | d
```

这里存在间接左递归：S ⇒ Aa ⇒ Bba ⇒ Sca ⇒ ...

**步骤1**：排序非终结符为S, A, B

**步骤2**：处理S（i=1，没有j<i）
S的产生式已经没有左递归：S → Aa | b

**步骤3**：处理A（i=2，j=1）
将A → Bb中的B替换为S的产生式：
A → Scb | db
但S → Aa | b，所以替换后：
A → Aacb | bcb | db
现在A有直接左递归，消除它：
```
A → bcbA' | dbA'
A' → acbA' | ε
```

**步骤4**：处理B（i=3，j=1和j=2）
将B → Sc中的S替换为S的产生式：
B → Aac | bc
将A替换为已处理的A的产生式：
B → bcbA'ac | dbA'ac | bc

**消除间接左递归后的文法：**
```
S → Aa | b
A → bcbA' | dbA'
A' → acbA' | ε
B → bcbA'ac | dbA'ac | bc
```

## 消除左递归的算法

以下是一个通用的消除左递归的算法：

```
1. 将非终结符排序为A₁, A₂, ..., Aₙ
2. 对每个i从1到n:
   a. 对每个j从1到i-1:
      i. 将每个产生式Aᵢ → Aⱼγ替换为所有Aᵢ → δγ，其中Aⱼ → δ是所有Aⱼ的产生式
   b. 消除Aᵢ产生式中的直接左递归
3. 删除无用产生式
```

## 注意事项

1. **ε产生式**：在消除左递归过程中可能引入ε产生式

2. **文法等价性**：消除左递归后的文法与原文法等价，即生成相同的语言

3. **适用范围**：该方法适用于任何不含ε-产生式循环的上下文无关文法

4. **推导复杂度**：消除左递归可能增加推导的长度，但不会改变语言的结构

## 消除左递归的意义

1. **解析算法兼容性**：许多自顶向下解析算法（如LL解析）要求文法没有左递归

2. **避免无限循环**：左递归会导致递归下降解析器陷入无限循环

3. **提高解析效率**：消除左递归后，解析过程更加高效和可预测

4. **理论研究价值**：在形式语言理论中，消除左递归是文法规范化的重要步骤

通过消除左递归，我们可以将上下文无关文法转换为更适合解析的形式，这对于编译器设计、语法分析和形式语言研究都具有重要意义。
